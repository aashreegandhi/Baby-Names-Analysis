# Baby-Names-Analysis
Tidy Tuesday 2022-03-22 Baby Names Dataset
Project Overview: This project investigates the evolution of American identity through the lens of naming conventions. Using over a century of data from the Social Security Administration, we test the "Individualism Hypothesis"—the theory that American society has transitioned from a "Collective Conformity" model (where most individuals shared a small pool of standard names) to a "Uniqueness" model characterized by phonetic diversity and social distinctiveness.
Research QuestionTo what extent has naming concentration declined since 1880, and is this trend driven by a genuine cultural shift toward individualism or simply a byproduct of population growth?
Analysis Plan (7-Step Framework)To provide a robust answer, the analysis follows a stepwise progression:Conformity Indexing: Calculating the "market share" of the Top 10 names by year and sex.Phonetic Extraction: Isolating name-ending sounds (last letters) to track linguistic diversity.Distributional Analysis: Examining naming frequency to justify the use of log-transformations in statistical modeling.Simple Linear Regression: Quantifying the annual rate of naming diversification.Adjusted Multiple Regression: Controlling for biological sex and total birth volume to isolate the cultural "Year" effect.Entropy Analysis: Modeling the expansion of the American "Phonetic Palette" used in modern naming.Sensitivity Testing: Filtering for high-volume names to ensure trends are not driven by data "noise" or rare outliers.Key FindingsThe Decay of Conformity: In 1880, ~41% of males shared a "Top 10" name. By 2017, this concentration dropped below 10%, indicating a statistically significant rise in naming individualism.Predictive Modeling: The adjusted regression model ($M_2$) yielded a significant negative coefficient for the year ($\beta = -0.002, p < .001$), confirming that the shift toward uniqueness persists even when controlling for population growth.Phonetic Expansion: There is a significant increase in the diversity of phonetic endings, with a modern preference for "soft" endings (vowels and 'n').Cultural Velocity: Modern names exhibit significantly shorter "peak popularity" lifespans compared to the "anchor" names of the early 20th century.Variable Constructiontop10_share: The proportion of total births accounted for by the ten most popular names in a given year.total_n: The total number of births recorded for that year/sex (used as a control for population size).last_letter: A categorical variable representing the phonetic ending of a name.Log-transformed Frequency: Because naming data is highly skewed (long-tail distribution), counts are log-transformed for statistical normality in model diagnostics.How to Run the AnalysisEnvironment: Ensure R (version 4.0+) is installed.Execution: Run babynames_analysis.R.Data Loading: The script uses the tidytuesdayR package with an automated GitHub fallback if the API is unavailable.Outputs:Console: Statistical summaries for all 4 regression models.Folder: An analysis_plots/ directory will be created containing 6 high-resolution PNG visualizations of the results.DependenciesThis project utilizes the pacman manager to handle the following libraries:tidyverse: Data wrangling and visualization.tidytuesdayR: Data acquisition.broom: Statistical model tidying.modelr: Diagnostic mapping.scales: Axis formatting.DiagnosticsTo ensure robustness, the script includes a Normal Q-Q Plot of residuals. The diagnostics confirm that the error terms follow a normal distribution, validating the use of OLS regression for these cultural trends.
